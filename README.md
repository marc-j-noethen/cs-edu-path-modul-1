# CS Edu Path Module 1

Module 1 forms the technical foundation of the entire cybersecurity learning path. The focus is on Python, technical fundamentals, networking, web basics and operating systems. This repository brings together the learning content, summaries and exercises for the first stage of the course.

## Overview

| Area | Content |
|---|---|
| Module objective | Solid technical foundation for subsequent security, cloud and DevSecOps topics |
| Focus | Python, IT fundamentals, networking, web, operating systems |
| Structure | Weekly folders with thematic learning units |
| Scope | 11 weekly folders, 65 topic folders |

## Topic Map

### Phase 1: Python and Technical Fundamentals
- Week 1: Introduction to Python, variables, IDE, terminal, editor shortcuts
- Week 2: Hardware, number systems, data encoding, lists, loops, functions
- Week 3: Data formats, debugging, dictionaries, strings, SQL, advanced SQL
- Week 4: Modules, files, error handling, OOP, open source, Git, regex

### Phase 2: Networks and the Web
- Week 5: Internet fundamentals, sockets, Wireshark, encryption, certificates
- Week 6: HTML, CSS, JavaScript, HTTP, Flask, Cookies, APIs, Authentication
- Week 7: Protocols, DNS, Proxies, TCP, UDP, Compression
- Week 8: IP, Subnetting, NAT, PAT, DHCP, VPN, Introduction to Operating Systems
- Week 9: Ethernet, ARP, VLANs, Troubleshooting, Connectivity, Wi-Fi

### Phase 3: Operating Systems and System Understanding
- Week 10: PowerShell, Processes, Threads, Scheduling, Memory, Executables
- Week 11: File Systems, Registry, Permissions, Services, Hardening, Unix & Linux

## Typical structure of a learning unit

- `1-Concepts-Tools-Terms/`
  Contains concise technical summaries, terms, tools and core concepts.
- `2-Exercises/`
  Contains the exercise and solution files for the respective topic.

Note: Individual topic folders may also contain older parallel folders from previous versions. For the current working structure, `1-Concepts-Tools-Terms` and `2-Exercises` are particularly relevant.

## What this module covers

After Module 1, you should be able to:

- read Python code and write simple automation scripts
- use the terminal, editor and Git confidently
- classify key network protocols and layer models
- understand basic web and API concepts
- master fundamental Windows, Linux and OS security concepts

## How to use this module

- Start on a weekly basis and work your way through the topic folders.
- First, use the content in `1-Concepts-Tools-Terms` to quickly get to grips with the topic.
- Then consolidate what you have learnt using `2-Exercises`.
- The summaries serve as a quick reference for revision and reference purposes.

## Position in the overall learning path

Module 1 forms the foundation for the following training sections:

- Module 2: Offensive and analytical cybersecurity practice
- Module 3: Cloud security, enterprise security and DevSecOps
- Module 4: Spezialisation

Those who have mastered this module thoroughly will have laid the technical foundations for the rest of the learning path.
