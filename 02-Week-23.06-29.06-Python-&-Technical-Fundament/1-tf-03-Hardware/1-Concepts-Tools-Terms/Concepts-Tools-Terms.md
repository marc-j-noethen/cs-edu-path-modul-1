## **📊 Summary according to the 80/20 Principle**

### Hardware vs. Software - The Core Difference

**Hardware** = Physical parts (tangible): processor, memory, hard drive, screen **Software** = Programs and instructions (intangible): Windows, apps, games

**Memory aid:** Hardware is the car, software is the driver.

### The 6 Core Components (by importance)

#### 1. **CPU (Processor) - The Brain**

- Executes all calculations
- **GHz** (e.g. 3.2 GHz) = speed (higher = faster)
- **Cores** (e.g. 8-core) = how many tasks can run simultaneously
- **Memory aid:** More cores = better multitasking, higher GHz = faster individual tasks

#### 2. **RAM (Working Memory) - Short-Term Memory**

- Stores currently open programs and data
- **Volatile**: content is lost when powered off
- **8 GB** = minimum today, **16 GB** = recommended, **32+ GB** = for professional work
- **IMPORTANT:** More RAM = more programs running simultaneously without slowdown
- **Windows tip:** Task Manager (`Ctrl+Shift+Esc`) shows RAM usage

#### 3. **Storage (Hard Drive/SSD) - Long-Term Memory**

- Stores files, programs, and the operating system permanently
- **HDD (old)**: Slow, mechanical, loud, cheap (rarely built-in anymore)
- **SSD (modern)**: Fast, quiet, robust, energy-efficient - **today's standard**
- **256 GB** = minimum, **512 GB** = recommended, **1 TB+** = for many files/games
- **Non-volatile**: data is retained when powered off

#### 4. **Motherboard/Mainboard - The Nervous System**

- Connects all components to one another
- Contains slots for CPU, RAM, SSD
- **Desktop**: components often interchangeable
- **Laptop**: components often soldered = **not upgradable!**

#### 5. **GPU (Graphics Card) - The Image Specialist**

- **Integrated**: part of the CPU, sufficient for office/browsing/video
- **Dedicated**: separate card for gaming, video editing, 3D work
- **Windows check:** Task Manager > Performance > GPU shows which GPU you have

#### 6. **Power Supply/Battery - Power Source**

- **Desktop**: internal power supply unit (PSU)
- **Laptop**: external adapter + internal battery

### The Most Important Ports

**Must know:**

1. **USB-C**: Modern, reversible, for everything (data, display, charging)
2. **USB-A**: Classic, rectangular, for mouse/keyboard/USB stick
3. **HDMI**: For monitors/televisions
4. **Audio jack (3.5mm)**: Headphones/speakers
5. **Ethernet (RJ-45)**: Network cable (faster than Wi-Fi)

**Good to know:**

- **Thunderbolt**: Super-fast USB-C (up to 40 Gb/s), for professional devices
- **DisplayPort**: Alternative to HDMI, often better for gaming monitors

### Critical Purchasing Decision: Not Upgradable!

**CAUTION with modern laptops (especially thin/light ones):**

Many components are **soldered** and CANNOT be expanded after purchase:

- RAM (working memory)
- SSD (hard drive)
- Often even the Wi-Fi card

**Consequence:** Whatever you choose at purchase, you keep forever!

**Buying recommendations:**

- **RAM**: Better to get 16 GB instead of 8 GB (if budget allows)
- **SSD**: Better to get 512 GB instead of 256 GB (files grow quickly)
- **External storage** is slower than internal SSDs

### Finding Hardware Info in Windows 11

**Fastest method:**

1. Press the `Windows key`
2. Type "System Information" or "msinfo32"
3. Press Enter

**Alternative (more clearly laid out):**

1. `Ctrl + Shift + Esc` (Task Manager)
2. Click the "Performance" tab
3. You'll see: CPU, RAM, GPU, and disk usage in real time

**What you'll find there:**

- CPU: model, cores, speed
- RAM: installed, available, type
- Storage: capacity, free space, type (SSD/HDD)
- GPU: model, dedicated or integrated

### The 3 Core Questions When Buying a Computer

1. **CPU**: At least 4 cores (e.g. Intel Core i5/i7, AMD Ryzen 5/7)
2. **RAM**: At least 16 GB (8 GB only for very basic use)
3. **Storage**: At least 512 GB SSD (never HDD on new devices!)

**Bonus tip:** With non-upgradable laptops, it's better to invest more NOW than to regret it later!

### Key Takeaways

**The 3 most important insights:**

1. **CPU + RAM + SSD** = The "holy trinity" - never cut corners here
2. **Modern laptops are often not upgradable** - think carefully before buying
3. **SSD instead of HDD** - no compromise anymore, SSDs are the standard and indispensable

**Memory aids:**

- **CPU** = How fast you think
- **RAM** = How much you can keep in your head at once
- **SSD** = How large your bookshelf is (and how fast you can find books)

## Tools Used, Technical Terms, and Important Vocabulary

|Term|Meaning|
|---|---|
|**Tools Used (macOS → Windows)**||
|System Information|Display hardware information (Windows: `System Information` via Start search or `msinfo32` in the Run dialog)|
|Applications > Utilities|Utilities folder for system tools (Windows: `Control Panel` or `Settings > System`)|
|Option + Apple Menu|Alternative system information (Windows: `Windows key + Pause` or `Settings > System > About`)|
|**Hardware Components**||
|Hardware|Physical, touchable parts of a computer (as opposed to software)|
|Software|Programs and instructions that tell the hardware what to do|
|Motherboard / Mainboard|Main circuit board - connects all components (Mac: Logic Board)|
|Logic Board|Apple's term for the motherboard in Macs|
|PCB (Printed Circuit Board)|Printed circuit board - the base of the motherboard|
|CPU (Central Processing Unit)|Main processor - the "brain" of the computer, executes calculations|
|Processor / Chip|Other terms for CPU|
|Core|Processor core - each core can process tasks independently|
|Multi-Core (dual, quad, octa)|Multiple cores (2, 4, 8) - enables multitasking|
|RAM (Random Access Memory)|Working memory - fast, temporary storage (content is lost when powered off)|
|Volatile Memory|Temporary storage - data is lost when powered off (RAM)|
|Non-Volatile Memory|Persistent storage - data is retained (SSD, HDD)|
|Unified Memory|Integrated memory in Apple Silicon chips (not expandable)|
|Memory Module / RAM Stick|Memory module - interchangeable RAM modules (not in all laptops)|
|**Storage Technologies**||
|HDD (Hard Disk Drive)|Hard disk drive - mechanical with rotating platters (slow, cheap, fragile)|
|SSD (Solid State Drive)|Solid-state drive - electronic with flash memory (fast, quiet, robust)|
|Storage Capacity|Storage capacity - measured in GB (gigabytes) or TB (terabytes)|
|Flash Memory|Flash memory - technology used in SSDs and USB sticks|
|**Graphics Processing**||
|GPU (Graphics Processing Unit)|Graphics processor - specialized in image processing|
|Integrated GPU|Integrated graphics - part of the CPU, sufficient for everyday tasks|
|Dedicated GPU|Dedicated graphics card - separate, more powerful graphics for gaming/video|
|Graphics Card|Graphics card - a separate component with its own GPU|
|**Power Supply & Cooling**||
|PSU (Power Supply Unit)|Power supply - converts electricity (Desktop: internal, Laptop: external adapter)|
|Power Adapter|Power adapter - external "brick" charger for laptops|
|Battery|Battery/accumulator - internal power supply for mobile devices|
|Cooling System|Cooling system - fans, heat sinks, heat pipes to prevent overheating|
|Heat Sink|Heat sink - metal block for heat dissipation|
|Thermal Throttling|Heat throttling - CPU/GPU slows down when overheating|
|**Units of Measurement**||
|GHz (Gigahertz)|Processor clock speed - billions of operations per second|
|GB (Gigabyte)|Unit of storage - approx. 1 billion bytes (RAM, storage)|
|TB (Terabyte)|Unit of storage - 1,000 GB|
|Gb/s (Gigabits per second)|Data transfer speed (e.g. for ports)|
|**Input/Output Devices**||
|Input Device|Input device - sends data TO the computer (keyboard, mouse, microphone)|
|Output Device|Output device - receives data FROM the computer (monitor, speakers, printer)|
|Peripheral|Peripheral device - external devices connected to the computer|
|**Ports**||
|USB-A|Classic rectangular USB connector (USB 2.0, 3.0, 3.1 with varying speeds)|
|USB-C|Modern oval, reversible connector for data, video, and power|
|Thunderbolt|High-speed interface (often with USB-C connector, up to 40 Gb/s) by Intel/Apple|
|HDMI|Video/audio connector for monitors and televisions|
|DisplayPort|Video connector for monitors (often better resolution/refresh rate than HDMI)|
|Ethernet (RJ-45)|Wired network connector|
|Audio Jack (3.5mm)|Headphone jack for headphones, speakers, microphone|
|SD Card Slot|Memory card slot (often for camera memory cards)|
|MagSafe|Apple's magnetic charging connector (detaches when pulled)|
|Docking Station / Hub|Expansion station with multiple ports (important for laptops with few ports)|
|**Further Concepts**||
|Bus|Data pathway on the motherboard for component communication|
|Soldered / Permanently Attached|Soldered - permanently connected, not upgradable (in many modern laptops)|
|Upgradable / User-Replaceable|Can be upgraded/replaced by the user|
|Form Factor|Form factor - physical size and format of a component|
|Multitasking|Running multiple programs simultaneously|

## Windows 11: Displaying Hardware Information

|Function|macOS|Windows 11|
|---|---|---|
|Open system overview|`Option + Apple Menu > System Information`|`Windows + Pause` or `Settings > System > About`|
|Detailed hardware info|`Applications > Utilities > System Information`|`Windows + R`, then type `msinfo32`|
|View CPU info|In System Information under "Hardware"|System Information > Processor or Task Manager (`Ctrl+Shift+Esc`) > Performance|
|View RAM info|System Information > Memory|System Information > Memory or Task Manager > Performance > Memory|
|View storage info (SSD/HDD)|System Information > Storage|System Information > Components > Storage or Disk Management|
|View GPU info|System Information > Graphics/Displays|Device Manager > Display Adapters or Task Manager > Performance > GPU|
|Quick access system info|`Spotlight (Cmd+Space)` → "System Information"|`Windows key` → "System Information" or "Device Manager"|
