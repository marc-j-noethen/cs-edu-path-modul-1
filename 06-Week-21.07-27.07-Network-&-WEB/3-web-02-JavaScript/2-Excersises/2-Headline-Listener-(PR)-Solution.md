# WEB 2 - Exercise 2: Headline Listener (PR)

## Task
Create an interactive JavaScript page that reacts to clicks and updates visible DOM content.

## Execution Environment
- Browser: local HTML file
- File: `web2-ex2/clickcounter.html`
- Technologies: HTML, JavaScript

## Approach
1. Created a button and display element in HTML.
2. Registered a `click` event listener.
3. Increased a counter on each click and updated the text in the DOM.

## Code Used / Files Used
- `web2-ex2/clickcounter.html`

## Result
The page reacts to clicks and displays `Times clicked: 7`.
