# Speedy McQueen (Physical Layer)

**Course:** Cyber Security Analyst – Network Technology | **Date:** 15 August 2025

---

## Task

**Objective:**  
Compare several speed tests and identify physical factors that influence the results.

**Requirements:**

- Take multiple measurements.
- Note down download, upload, latency and server location.
- Compare results with ISP values.

---

## Solution

```text
Pattern analysis:
- Results from different providers are often similar, but may vary slightly.
- Slight variations between test runs are normal, as server location, network load and Wi-Fi conditions vary.
- The measured average speed is often lower than the ISP’s maximum value, as the ISP value is a theoretical or optimal peak value.

Typical factors influencing the physical layer:
- Type of connection to the home (fibre optic, cable, DSL)
- Quality and length of cabling
- Wi-Fi interference and distance from the router
- Simultaneous use by other devices
- Latency and load on the test server
```

**Alternative (compact):**

```text
Speed tests measure reality; ISP figures often describe an ideal.
```

## Explanation / Concepts

|Concept|Description|
|---|---|
|Throughput|Actual usable data rate.|
|Latency|Time taken for a packet to travel there and back.|
|Variation|Networks are never identical in every run.|

---

## Rules / Logic

```text
Measured value ≠ marketing claims.
Practical values always depend on the environment and load.
```
