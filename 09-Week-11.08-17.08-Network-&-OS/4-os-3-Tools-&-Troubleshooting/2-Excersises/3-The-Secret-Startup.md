# 🐍 The Secret Startup (Registry Persistence)

**Course:** Cyber Security Analyst - OS Technology | **Date:** 14 August 2025

---

## Task

**Objective:**  
Identify the autostart persistence of a batch script via the registry and name the launched process and the opened file.

**Requirements:**

- Identify the autostart mechanism in `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- Name the launched process and the opened file.
- Specify the log file and its path.
- Describe the answer clearly as a registry artefact.

- Output:

    - Programme name after login
    - Path to the open file
    - Full registry key + value name + data

---

## Solution

```text
Result:
1. Automatically started programme:
   notepad.exe

2. Opened file:
   C:\Users\Public\Documents\System_Event_Log.txt

3. Persistence mechanism:
   - Registry key:
     HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
   - Value name:
     SystemEventViewer
   - Value data:
     notepad.exe C:\Users\Public\Documents\System_Event_Log.txt

4. Log file:
   - Full path: C:\Users\Public\Documents\System_Event_Log.txt
   - Expected content: the log or text file artefact generated by the script, which is opened directly in Notepad upon login

Classification:
The batch script uses classic user-run persistence.
This causes Notepad to be launched automatically with a seemingly harmless file upon the next interactive login.

Note:
The specific association of `notepad.exe` and the log file is derived from the task’s instructions and is therefore the technically correct lab result for this scenario.
```

**Alternative (compact):**

```text
This is classic `HKCU\...\Run` persistence: a harmless-sounding value launches Notepad with a prepared file upon login.
```

## Explanation / Concepts

|Concept|Description|
|---|---|
|Run Key Persistence|User-specific registry mechanism for programmes that start automatically at login.|
|Autoruns Artifact|Such entries can be easily found using Registry Editor, Autoruns or `reg query`.|
|User Context|As the key is located under HKCU, the persistence applies only to the user in question.|

---

## Rules / Logic

```text
A `Run` entry under HKCU starts when the user logs in.
Harmless-sounding value names do not make persistence any less suspicious.
The file path, value name and command line must be documented together.
```
