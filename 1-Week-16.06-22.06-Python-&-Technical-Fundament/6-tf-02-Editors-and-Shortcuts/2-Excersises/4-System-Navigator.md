## Task

**Objective:** Navigate the Windows 11 file system and apps efficiently by using keyboard shortcuts in File Explorer and Windows Search.

## Solution

### Environment
```text
OS: Windows 11
Shell: File Explorer / Windows Search
```

---

## Challenge A: File System Frenzy

### Procedure

**1. Open the Desktop in File Explorer**
```text
Win+E
Alt+D
%USERPROFILE%\Desktop
Enter
```

**2. Create a new folder `TF2_Challenge`**
```text
Ctrl+Shift+N
Type TF2_Challenge
Enter
```

**3. Duplicate a file**
```text
1. Select shortcut_practice.txt
2. Ctrl+C
3. Ctrl+V
```
Result: A copied file appears in the same folder.

**4. Rename the copied file**
```text
1. Select the copied file
2. F2
3. Type practice_copy.txt
4. Enter
```

**5. Move the file into the folder**
```text
1. Select practice_copy.txt
2. Ctrl+X
3. Open TF2_Challenge (Enter)
4. Ctrl+V
```

### Shortcuts for Challenge A

| Shortcut | Action |
|----------|--------|
| `Win+E` | Open File Explorer |
| `Alt+D` | Focus address bar |
| `Ctrl+Shift+N` | New folder |
| `Ctrl+C` / `Ctrl+V` | Copy / paste |
| `Ctrl+X` / `Ctrl+V` | Move via cut / paste |
| `F2` | Rename |

## Challenge B: Quick Launch & Capture

### Procedure

**1. Open Calculator using Windows Search**
```text
Win+S
Type Calculator
Enter
```

**2. Switch back to Sublime Text**
```text
Alt+Tab
```

**3. Take a screenshot of the active Sublime Text window**
```text
Alt+PrtScn
```
The active window is copied to the clipboard and can then be pasted into Paint, Snipping Tool, or another document.

### Shortcuts for Challenge B

| Shortcut | Action |
|----------|--------|
| `Win+S` | Open Search |
| `Alt+Tab` | App switcher |
| `Alt+PrtScn` | Screenshot of active window |
| `Win+Shift+S` | Open Snipping Tool overlay |

## Challenge C: File Inspector

### Procedure

**1. Navigate to the file in File Explorer**
```text
Win+E
Alt+D
%USERPROFILE%\Desktop
Enter
Arrow keys -> shortcut_practice.txt
```

**2. Preview the file**
```text
Alt+P
```
This toggles the Preview Pane in File Explorer.

**3. Open Properties**
```text
Alt+Enter
```

### Shortcuts for Challenge C

| Shortcut | Action |
|----------|--------|
| `Alt+P` | Toggle Preview Pane |
| `Alt+Enter` | Open Properties |
| `Esc` | Close active dialog or preview context |
