# 🐍 Introduction to GitHub

**Course:** Cyber Security Analyst – Python Basics | **Date:** 11 July 2025

---

## Task

**Objective:** Complete the standard “Hello World” tutorial on GitHub to practise creating a repository, creating branches, making commits and opening pull requests directly via the GitHub web interface.

**Requirements:**
- Repository: `hello-world`
- Branch: `readme-edits`
- Actions: Create repository, create branch, edit README.md, commit changes, open pull request, merge pull request
- Output: Screenshot of the repository after successful merge

---

## Solution

**Steps taken:**

1. **Repository created:** Created the `hello-world` repository on GitHub
2. **Branch created:** Created a new branch `readme-edits`
3. **README.md edited:** Made changes to the README file in the branch
4. **Commit performed:** Committed changes
5. **Pull Request opened:** Created a PR from the `readme-edits` branch to the `main` branch
6. **Pull request merged:** PR successfully merged

**Evidence:** Screenshots show:
- Screenshot 1: Repository overview with edited README
- Screenshot 2: Commit history with merged pull request
