# Desktop Organiser (Windows Intro)

**Course:** Cyber Security Analyst – OS Technology | **Date:** 08 August 2025

---

## Task

**Objective:**  
To practise basic Windows desktop and file operations.

**Requirements:**

- Create a folder and a text file.
- Write content to `Windows_Basics.txt`.
- Find the computer name and change the desktop background.

---

## Solution

```text
Sample result:
Desktop
└── MyCyberSecJourney
    └── OS_Notes
        └── Windows_Basics.txt

File content:
`The Windows desktop is my new digital playground!`

Computer name:
`lukas`  (Example value from the current Windows system)

Explanation regarding the background colour:
In some Windows versions or activation states, a direct colour selection is not always available or is organised differently graphically.
In that case, at least the background image can certainly be changed.
```

**Alternative (compact):**

```text
Create folder structure, populate file, document system name, customise desktop.
```
