## Solution

### Task 1: All columns of a table
```sql
SELECT * FROM movies;
```

### Task 2: Titles of all films
```sql
SELECT title FROM movies;
```

### Task 3: Director of all films
```sql
SELECT director FROM movies;
```

### Task 4: Title and director
```sql
SELECT title, director FROM movies;
```

### Task 5: Title and year
```sql
SELECT title, year FROM movies;
```

### Task 6: All information
```sql
SELECT * FROM movies;
```

## Notes

- **`SELECT *`:** Select all columns
- **`SELECT column1, column2`:** Select specific columns
- **`FROM table`:** Specifies the source table
- **Order:** SELECT → FROM
